# 시놉시스 (Synopsis) — 초안, 확정 아님

**이 문서는 자리만 잡아둔 초안이다.** 장르·스토리·캐릭터는 사용자가 결정할 창작 영역이라 임의로 확정하지 않았다 — `docs/command-playbook.md` #4행("실제 게임 시작하자")도 "장르·핵심 루프"를 사용자 판단 항목으로 못박아 뒀다. 아래는 지금 저장소에 있는 것(엔진 데모, Unity-chan 에셋)만 근거로 최소 구조를 채운 자리표시자다 — 그대로 써도 되고, 방향을 알려주면 다시 쓴다.

## 지금 확실한 것

- 엔진: C++20/DX11 2D+3D 하이브리드, 3인칭 3D 캐릭터(스켈레탈 애니메이션, `docs/model-animation-research.md`) 렌더링 검증됨.
- 캐릭터 에셋: Unity-chan(`assets/models/unitychan/`) — 애니메이션 클립 26개(대기/걷기/뛰기/점프/피격/승리/패배 등, `render/r3d/CharacterAnimationClips.h`) 보유.
- 씬 구조: Title → InGame, Settings 오버레이(`docs/scene-flow-design.md`).

## 다음 결정이 필요한 것

1. 장르·핵심 루프 — 이게 정해져야 InGame 화면의 실제 콘텐츠(`Simulation`의 데모 페이로드 교체)를 설계할 수 있다.
2. 주인공 확정 — Unity-chan을 그대로 쓸지, 자체 캐릭터로 갈지(자체 캐릭터면 리깅·클립 세트를 새로 준비해야 함, `docs/model-animation-research.md` §5.2a).
3. 세계관/배경 — 레벨 디자인·배경 3D 씬 구성에 필요.

## 사용 방법 (How to use)

이 문서는 콘텐츠 문서라 "API 사용법"은 없다. 갱신 규칙만:

- 장르/스토리가 정해지면 위 표를 확정값으로 덮어쓰고 이 파일 맨 위 "초안, 확정 아님" 표기를 지운다.
- `docs/game-settings.md`·`docs/scene-flow-design.md`는 이 문서의 결정과 독립적으로 이미 동작한다 — 시놉시스가 없어도 엔진 자체는 안 막힌다.
